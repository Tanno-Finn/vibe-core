# Open Questions

Decisions that are **yours to make**, parked here by the agent so the work isn't blocked
waiting on you. The agent adds an entry when it hits a choice it shouldn't make alone (a
design call, "should X stay this way?") but that needn't stop everything right now. You
answer here in the file or just in conversation. See
[`base/BOOKKEEPING.md`](base/BOOKKEEPING.md) for the contract; `/status` surfaces the open
ones. This is committed project knowledge — no personal data here.

Two sections: **Open** (waiting on you) and **Answered** (kept as a short record, newest at
the bottom). Only questions that actually *shape the work* belong here — not micro-decisions.
