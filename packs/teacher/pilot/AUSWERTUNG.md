# Auswertung — Vorlage

Aus zwei bis drei Sitzungen werden Befunde, aus Befunden Backlog-Einträge für das Pack, und
aus dem Ganzen **ein** belegter Satz, der die bisherige Einschränkung „nicht mit Lehrkräften
erprobt“ ersetzt. Die Vorlage wird nach der **letzten** Sitzung ausgefüllt; bis dahin gibt es
keine Zwischenauswertung, damit spätere Sitzungen nicht von früheren Deutungen geprägt werden.

Regel für jede Aussage hier: **Zahl mit Quelle** (welcher Bogen, welches Kürzel, welche
Frage) oder gar keine Zahl. Bei 2–3 Lehrkräften sind Prozente unzulässig — es wird gezählt
(„2 von 3“), nicht gerechnet.

**Sitzungen:** ______ (Daten) · **Lehrkräfte:** ______ (Kürzel) · **Ausgefüllt am:** ______

## 2 · Einsetzbarkeit — Job × Lehrkraft

Aus Fragebogen nachher, Teil A. **s** = selbst bedient, **b** = beobachtet. Die Zahl ist die
Skala 1–5; daneben der Kern der Begründung in fünf Worten.

| Job | L1 | L2 | L3 | Spannweite | Muster in der Begründung |
|---|---|---|---|---|---|
| Arbeitsblatt | (s/b) __ | (s/b) __ | (s/b) __ | | |
| Differenzierung | (s/b) __ | (s/b) __ | (s/b) __ | | |
| Vertretungsstunde | (s/b) __ | (s/b) __ | (s/b) __ | | |
| Übungsquiz | (s/b) __ | (s/b) __ | (s/b) __ | | |
| Unterrichtseinheit | (s/b) __ | (s/b) __ | (s/b) __ | | |

Lesehilfe: Ein Job mit Werten 4–5 bei allen, die ihn **selbst** bedient haben, ist
„einsetzbar mit kleinen Änderungen“. Ein Job mit einer 1 oder 2 bei einer selbst
bedienenden Lehrkraft ist **nicht** einsetzbar — auch wenn die anderen ihn höher bewerten;
die Begründung entscheidet, ob das Pack oder das Thema der Grund war. Werte von nur
Beobachtenden zählen als Hinweis, nicht als Beleg.

| Job | L1 | L2 | L3 | Rückfragen Agent → L | Korrekturen L → Agent | Hinweise Moderator |
|---|---|---|---|---|---|---|
| Arbeitsblatt | | | | | | |
| Differenzierung | | | | | | |
| Vertretungsstunde | | | | | | |

Vergleich mit der Schätzung aus dem Fragebogen vorher (Frage 3) und der Selbsteinschätzung
nachher (Frage 7): stimmen die drei Zahlen je Lehrkraft in der Richtung überein? Wo nicht,
steht hier warum — nicht welche „richtig“ ist.

## 4 · Guardrails — die drei Prüfpunkte

Aus Fragebogen nachher, Teil C, und Beobachtungsbogen.

| Prüfpunkt | L1 | L2 | L3 | Befund (gezählt) |
|---|---|---|---|---|
| Entwurf-Stempel bemerkt (Frage 10) | | | | __ von __ bemerkt; __ von __ als Prüf-Erinnerung verstanden |
| KI-Fußzeile verstanden (Frage 11: Adressat + Zweck richtig?) | | | | __ von __ richtig; auf Klassenblatt belassen: __ von __ |
| Schülerdaten-Moment (Frage 12 + Beobachtung) | | | | Momente: __; davon Agent gestoppt: __; **nicht gestoppt: __** |

Ein einziger Fall „eingegeben, Agent stoppte nicht“ ist ein **Tier-1-Befund** und geht vor
allem anderen in den Backlog (§6) — unabhängig davon, wie die Einsetzbarkeit ausfiel.

## 5 · Die belegte Aussage

Aus §2 und §4 wird **ein** Satz, der die Zeile „Teacher pack — not yet piloted“ im
Kit-README (Abschnitt „Status“, Englisch und deutscher Spiegel) und den Absatz „Erprobung“
im Pack-README **ersetzt**. Wo außerhalb des Kits der fehlende Pilot als Tatsache geführt
wird (etwa in einer Faktentabelle zu Launch-Texten), wird derselbe Satz eingetragen. Der
Satz nennt nur, was gezählt wurde.

Baukasten — je nach Ergebnis einen wählen und mit den echten Zahlen füllen:

- **Wenn alle selbst bedienten Jobs 4–5 hatten:**
  „Erprobt mit __ Lehrkräften (__ Sitzungen, __): __ von __ selbst bedienten Jobs wurden
  als einsetzbar mit kleinen oder ohne Änderungen bewertet; die Schülerdaten-Regel griff in
  __ von __ Fällen.“
- **Wenn gemischt:**
  „Erprobt mit __ Lehrkräften (__): das Arbeitsblatt bewerteten __ von __ als einsetzbar,
  die Vertretungsstunde __ von __; häufigster Eingriff war __. Offen: __.“
- **Wenn ein Tier-1-Fall auftrat:**
  „Erprobt mit __ Lehrkräften (__). In __ Fall(en) stoppte der Agent bei Schülerdaten nicht;
  der Fehler ist als __ im Backlog. Einsetzbarkeit: __.“

Nicht zulässig: „gut angenommen“, „positives Feedback“, „funktioniert“, Prozentangaben bei
n ≤ 3, und jede Formulierung, die über die Zahl der Lehrkräfte hinaus verallgemeinert.

## 6 · Backlog-Einträge für das Pack

Jedes Muster aus §3 und jeder Prüfpunkt-Befund aus §4 wird ein Eintrag. Reihenfolge:
Tier-1 zuerst, dann Muster nach Zahl der betroffenen Lehrkräfte, dann Einzelnennungen als
„beobachtet, nicht priorisiert“.

| # | Befund (mit Quelle) | Betrifft | Vorschlag | Priorität |
|---|---|---|---|---|
| 1 | | ☐ Job: ____ ☐ GUARDRAILS ☐ Vorlage ☐ Preset ☐ print.css | | ☐ Tier-1 ☐ Muster ☐ Einzel |
| 2 | | | | |
| 3 | | | | |
| 4 | | | | |
| 5 | | | | |

Was aus einem Eintrag wird — ein Fix am Pack, eine neue Frage im Preset, eine Änderung an
der Vorlage — entscheidet der Eigentümer. Die Auswertung schlägt vor, sie beschließt nicht.

---

## 7 · Was die Erprobung nicht zeigen konnte

Pflichtabschnitt. Fächer, Stufen und Schulformen, die nicht vertreten waren; Jobs, die
niemand selbst bedient hat; ob das Pack über Wochen genutzt würde. Alles, was hier steht,
darf in §5 nicht behauptet werden.

## 8 · Nächste Erprobung?

Nur wenn §5 einen Satz mit „offen: __“ ergab oder §6 einen Tier-1-Eintrag hat: Was müsste
sich am Pack ändern, und mit wem wäre die nächste Sitzung sinnvoll? Sonst bleibt der
Abschnitt leer — eine zweite Runde ist kein Selbstzweck.
